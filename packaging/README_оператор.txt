Masking — локальный сервис маскирования персональных данных

Версию сборки и контрольную сумму exe см. в файле SHA256.txt рядом.

СОСТАВ ПАПКИ
- masking-service.exe   — программа (запускается двойным кликом).
- _internal\            — библиотеки программы (не трогать).
- data\                 — хранилище карт, проектов и файлов. Создаётся при первом
                          запуске; пустая база masking.db положена заранее.
- compat.txt            — номер версии и схемы данных (для установщика).
Данные ПОРТАТИВНЫ — лежат рядом с exe и переносятся вместе с папкой.

КАК ЗАПУСТИТЬ
1. Держите masking-service.exe, папку _internal и папку data ВМЕСТЕ в одной
   папке (не переносите exe отдельно). Программа хранит данные рядом с собой.
2. Запустите masking-service.exe. В браузере откроется http://127.0.0.1:8765/.
3. Создайте проект, перетащите .docx или .xlsx — файлы маскируются локально,
   наружу ничего не отправляется.
4. Для демаскирования загрузите замаскированный документ в раздел
   «Демаскирование» этого же проекта.

КУДА ПОПАДАЮТ ФАЙЛЫ
- База проектов и реестр: data\masking.db (рядом с exe).
- Загруженные и обработанные документы: data\files\<номер проекта>\.
- Логов работы не ведётся: содержимое документов нигде не записывается.

КАК ОБНОВИТЬ ВЕРСИЮ
Для обновления НЕ разворачивайте пакет заново на существующую папку, иначе
потеряете карту соответствий и проекты.
1. Используйте «Установить_Masking.exe» из новой поставки — установщик
   увидит существующую установку и сохранит папку data при обновлении.
2. Либо вручную: закройте программу (окно браузера и сам exe), замените
   masking-service.exe и папку _internal из новой папки, папку data НЕ
   трогайте.

ТРЕБОВАНИЯ
- Windows 10/11 (64-разрядная).
- Браузер по умолчанию для открытия веб-интерфейса.

БЕЗОПАСНОСТЬ
- Карта соответствий (data\masking.db) содержит оригинальные ФИО и номера.
  Это и есть персональные данные. Храните папку в надёжном месте —
  BitLocker, зашифрованный раздел, не оставляйте на общих дисках.
- Удаление проекта в интерфейсе необратимо стирает его карту и файлы.
- Сервис слушает ТОЛЬКО 127.0.0.1 — наружу порт не открывается.
- SmartScreen/антивирус может предупреждать, если программа не подписана
  сертификатом. Подлинность сборки подтверждает тот, кто передал поставку
  (по SHA-256 из SHA256.txt).
