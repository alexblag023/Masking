# Masking — локальный сервис маскирования ПДн в Word и Excel

Запускается как `masking-service.exe`, поднимает сервис на `http://127.0.0.1:8765/` (если порт занят — на свободном) и открывает веб-форму в браузере. Данные не покидают компьютер, наружу сервис не слушает.

## Использование
- Веб-форма: выберите `.docx` / `.xlsx`, режим и типы данных, файл скачается как `<имя>.masked.docx|xlsx`.
- API: `POST /api/mask` (multipart: `file`, `mode` = `tag|pseudo|stars`, `kinds` — можно несколько), ответ — файл; статистика в заголовке `X-Masking-Stats`. Swagger: `/docs`.

```
curl -F file=@договор.docx -F mode=pseudo -o out.docx http://127.0.0.1:8765/api/mask
```

Режимы: `tag` → `[ФИО]`; `pseudo` → `[ФИО_1]` (одно значение — один номер); `stars` → `***` с сохранением длины.

## Что находится
ФИО (полные и с инициалами), телефоны РФ, email, СНИЛС и ИНН (с проверкой контрольной суммы), банковские карты (Luhn), паспорт РФ (рядом со словом «паспорт»/«серия»), дата рождения (рядом с «дата рождения», «д.р.»).
ИНН из 10 цифр (юрлица) маскируется только рядом со словом «ИНН».

Покрытие в docx: текст, таблицы, колонтитулы, текстовые поля, гиперссылки; ПДн, разбитые на несколько форматированных фрагментов, находятся. В xlsx: все листы, значения, комментарии; формулы не трогаются. Метаданные (автор и др.) очищаются.

## Ограничения
- Только `.docx` и `.xlsx` (`.doc`/`.xls` пересохраните). Файлы с паролем не поддерживаются.
- Детекция на правилах (regex), без ML: адреса, названия организаций, ФИО без отчества/инициалов не ловятся. Это не гарантия полной анонимизации — проверяйте результат.
- В xlsx openpyxl не сохраняет часть объектов (диаграммы, картинки, макросы).
- Не маскируются: сноски docx, изображения, имена листов, defined names.

## Сборка exe
exe для Windows нужно собирать на Windows:
- локально: `build.bat` → `dist\masking-service.exe`;
- или через GitHub Actions (`build-exe`): артефакт `masking-service-windows`.

Разработка: `pip install -r requirements-dev.txt`, `python main.py`, `pytest`.
