# Masking — локальный сервис маскирования ПДн с проектами и обратимостью

Portable-программа для Windows: папка с `masking-service.exe` поднимает локальный сервис на `http://127.0.0.1:8765/` и открывает в браузере веб-интерфейс. Все данные (проекты, карта «оригинал ↔ токен», входные и выходные файлы) хранятся в папке `data/` рядом с exe. Папку можно скопировать на флешку или на другой компьютер — программа запустится так же.

## Что умеет

- **Маскирование** .docx и .xlsx: ФИО и адреса заменяются на токены вида `[ФИО_1]`, `[АДРЕС_1]`, с указанием падежа у ФИО (`[ФИО_1:дат]`).
- **Демаскирование**: обратно восстанавливает оригиналы по карте проекта. ФИО возвращаются в том падеже, в котором стояли (точная форма из реестра), либо склоняются pymorphy3.
- **Проекты.** Один человек в проекте получает один и тот же номер, даже если он встречен в разных падежах в разных документах. Это и есть смысл проекта.
- **Реестр сущностей.** Отдельный раздел: список «тип → токен → оригинал → сколько раз → в каких документах». Оригиналы по умолчанию скрыты точками, раскрываются кнопкой.
- **История.** В разделах «Маскирование» и «Демаскирование» лежат пары вход → выход, оба скачиваются.
- **Светлая и тёмная тема.** Авто по системе, можно переключить вручную.
- **Другие типы ПДн.** Телефоны, email, СНИЛС, ИНН, карты, паспорт, дата рождения находятся теми же регулярками, что и в v1. В обратимом режиме этой версии (API `/projects/{id}/mask`) они не маскируются; обратимость имеет смысл только для ФИО и адресов. Для необратимого маскирования остальных типов можно использовать старый эндпоинт из прошлой версии (его интерфейс мы не удаляли на уровне кода, но из UI убрали в пользу проектов).

## Что внутри

- Детекция ФИО и адресов: **slovnet NER** (нейросеть ~29 МБ, встроена в exe) + regex для адресов, инициалов и капса. Соседние PER-спаны склеиваются, ФИО внутри адресов отбрасываются.
- Падежи и склонение: **pymorphy3**, с кэшем выбранных форм в реестре.
- Хранилище: **SQLite** в `data/masking.db`, WAL. Файлы в `data/files/<project_id>/`.
- Веб: **FastAPI** + одностраничное приложение на чистом HTML/CSS/JS, без внешних ресурсов — работает офлайн.
- Сборка: **PyInstaller** в `dist/masking-service/` (onedir).

## Безопасность и 152-ФЗ

- Карта соответствий содержит оригинальные ФИО и адреса — это сами персональные данные. **В текущей версии она хранится в SQLite в открытом виде.** Доступ к папке `data/` = доступ к персональным данным.
- Это осознанный выбор для первой portable-версии: paroль/ключ усложняют перенос флешки и не защищают от атакующего с правами на этот компьютер.
- Храните папку `data/` в надёжном месте (BitLocker, зашифрованный раздел). При необходимости включим шифрование паролем проекта — архитектура его поддерживает (`entity.value_enc` зарезервировано в схеме).
- Удаление проекта стирает карту и файлы полностью: ранее замаскированные документы станет невозможно демаскировать. Это по дизайну (right to erasure).

## Использование

Запустите `masking-service.exe`. Откроется браузер, в нём:
1. Создайте проект (например, «Договоры 2026»).
2. Раздел **Маскирование** → перетащите .docx или .xlsx → скачайте результат.
3. Раздел **Сущности** → посмотрите, что найдено.
4. Раздел **Демаскирование** → загрузите замаскированный документ (вернувшийся от получателя) → скачайте восстановленный.

### API

- `POST /api/projects {"name"}` — создать;
- `GET /api/projects` — список;
- `DELETE /api/projects/{id}` — каскадное удаление;
- `POST /api/projects/{id}/mask` (multipart `file`) → файл с заголовками `X-Masking-Stats`, `X-Document-Id`;
- `POST /api/projects/{id}/unmask` (multipart `file`) → файл с `X-Unmasking-Stats` (включая `unknown` — токены, которых нет в проекте);
- `GET /api/projects/{id}/entities?kind=FIO|ADDR&q=...`;
- `GET /api/projects/{id}/history/{mask|unmask}` — пары вход/выход;
- `GET /api/documents/{id}/download` — скачать документ по id.

Swagger: `/docs`.

## Сборка

### Portable для Windows

На Windows: `build.bat`. Результат — `dist\masking-service\` целиком (exe + `_internal\`), ≈ 150 МБ. Копируйте всю папку.

Либо через GitHub Actions (workflow `build-exe`): собирает на `windows-latest`, запускает exe и дёргает `/api/health`, выкладывает артефакт `masking-service-portable-windows` — zip с portable-папкой.

### Разработка

```
pip install -r requirements-dev.txt
python main.py
pytest
```

Переменная `MASKING_HOME` переопределяет папку данных (удобно для тестов и для раздельных «профилей»).

## Ограничения

- Поддерживаются только `.docx` и `.xlsx`. Старые `.doc` / `.xls` — пересохранить.
- Детекция не идеальна: ФИО без отчества/инициалов и адреса, не похожие на российский шаблон (без «ул.», без города), могут не находиться. В UI пока нет ручной правки реестра — она в плане на v1.5.
- Для демаскирования критично не ломать токены. Word в стандартных операциях их не портит, но если получатель начал токен копировать по буквам, автозамена может превратить его во что-то другое — тогда он попадёт в список `unknown`.
- Файлы с паролем не поддерживаются.
- В xlsx openpyxl не сохраняет часть объектов (диаграммы, картинки, макросы) — это ограничение библиотеки.
- Метаданные (автор, последний редактор, комментарии) очищаются при маскировании.
